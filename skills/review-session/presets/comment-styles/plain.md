# Comment style: plain prose

Posted comments are plain prose with no label prefixes.

## Rules

- Don't prefix bodies with labels. The draft's `label` and `blocking` fields
  are for ordering only.
- Make blocking items explicit in words, for example by ending with "This one
  needs fixing before merge." State what would resolve it.
- Phrase questions as questions. Mark optional ideas as optional ("Optional:",
  "Not blocking, but…").
- Keep comments short: lead with the point, then add detail.
